# Curriculum

22-week roadmap from May 11, 2026 to October 11, 2026.

**Daily study target:** 3–4 focused hours  
**Weekly total:** 20–25 hours  
**Web track:** ~10–12 hours/week  
**Data Engineering track:** ~8–10 hours/week  

---

## Phase 1: Foundations (Weeks 1–4)
May 11 – June 6, 2026

### Week 1 — JS Basics & SQL SELECT
**Web:** Variables (var/let/const), data types, operators, MDN fundamentals  
**Data:** What is a database, SELECT, WHERE, ORDER BY, LIMIT  
**Assignment:** JS calculator + 20 SQL queries on jobs dataset

### Week 2 — Control Flow & Aggregations
**Web:** if/else, loops, functions, DOM basics  
**Data:** COUNT, SUM, AVG, GROUP BY, HAVING  
**Assignment:** DOM task list + SQL aggregation analysis

### Week 3 — Data Structures & Joins
**Web:** Arrays (push/pop/slice), objects (keys/values/entries)  
**Data:** INNER JOIN, LEFT JOIN, RIGHT JOIN, FULL OUTER JOIN  
**Assignment:** Array/object mini app + joins practice report

### Week 4 — Review, Git & NULL Handling
**Web:** Debugging, Git fundamentals, GitHub  
**Data:** NULL handling (COALESCE, NULLIF, IS NULL)  
**Assignment:** Combined markdown progress report

---

## Phase 2: Deeper JS & Production SQL (Weeks 5–8)
June 7 – July 4, 2026

### Week 5 — ES6+ & CTEs
**Web:** Destructuring, spread/rest, map/filter/reduce, Maps/Sets  
**Data:** Subqueries (correlated and non-correlated), WITH (CTEs)  
**Assignment:** API fetching app + CTE practice queries

### Week 6 — OOP, Modules & Window Functions
**Web:** Closures, classes & prototypes, ES modules  
**Data:** ROW_NUMBER, RANK, DENSE_RANK, LAG, LEAD, SUM OVER  
**Assignment:** OOP refactor + window functions report

### Week 7 — Async JS & Data Cleaning
**Web:** Promises, async/await, Fetch API, error handling  
**Data:** Data cleaning (TRIM, REPLACE, CAST, duplicate detection)  
**Assignment:** Async app with real API + data cleaning SQL script

### Week 8 — Tooling & SQL Portfolio Project 1
**Web:** Advanced Git (branching, PRs, conventional commits)  
**Data:** Full exploratory SQL analysis — dataset → findings → README  
**Assignment:** SQL Portfolio Project 1 (published to GitHub)

---

## Phase 3: TypeScript, Next.js Bridge & Data Modelling (Weeks 9–12)
July 5 – August 1, 2026

### Week 9 — TypeScript Basics & Normalisation
**Web:** TypeScript intro, everyday types, interfaces vs type aliases  
**Data:** ER diagrams, primary/foreign keys, 1NF/2NF/3NF  
**Assignment:** TS file conversion + normalised schema design

### Week 10 — TS Functions, Narrowing & Star Schema
**Web:** Function types, type narrowing, discriminated unions  
**Data:** OLTP vs OLAP, fact tables, dimension tables, grain  
**Assignment:** Typed Learning OS models + star schema design

### Week 11 — Generics, Next.js Start & Warehousing
**Web:** Generics basics, Learn Next.js official course (Ch 1–3)  
**Data:** Data warehouse concepts, ETL vs ELT, data marts  
**Assignment:** First Next.js dashboard page + warehouse tables in PostgreSQL

### Week 12 — Combined: Learning OS Database
**Web:** Next.js data fetching in Server Components  
**Data:** SQL Portfolio Project 2 — full schema design  
**Assignment:** Complete Learning OS database schema with documentation

---

## Phase 4: Build the Platform (Weeks 13–17)
August 2 – August 29, 2026

### Week 13 — App Shell & Auth
**Web:** App Router layouts, navigation, NextAuth setup

**Assignment:** Working app shell with auth and navigation

### Week 14 — Roadmap & Lesson Pages

**Assignment:** Roadmap page + lesson detail page

### Week 15 — Assignments & Submissions

**Assignment:** XP + streak + weekly score engine with unit tests

### Week 17 — Analytics Dashboard
**Web:** Recharts integration, responsive charts, data visualisation

**Assignment:** Full analytics dashboard
