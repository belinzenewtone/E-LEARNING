# Data Engineering Skills Audit

## Why This Matters

You've completed ~20 weeks of data engineering curriculum. Before moving on, take stock: What can you actually do? What needs more work? What should you learn next? A skills audit turns "I learned SQL" into specific, demonstrable competencies.

## Core Concepts

### Self-Assessment Framework

Rate each skill 1-5:
- 1 — Heard of it
- 2 — Can explain it
- 3 — Can do it with documentation
- 4 — Can do it independently
- 5 — Can teach it to someone else

### Skills Checklist

**SQL Fundamentals**
- [ ] SELECT with WHERE, ORDER BY, LIMIT
- [ ] Aggregate functions (COUNT, SUM, AVG, MIN, MAX)
- [ ] GROUP BY and HAVING
- [ ] JOINs (INNER, LEFT, FULL, self-joins)
- [ ] NULL handling (COALESCE, NULLIF, IS NULL)
- [ ] Subqueries and CTEs

**Advanced SQL**
- [ ] Window functions (ROW_NUMBER, RANK, LAG, LEAD)
- [ ] Running totals and moving averages
- [ ] Data cleaning in SQL
- [ ] Exploratory data analysis
- [ ] Query optimization basics

**Data Modeling**
- [ ] ER diagrams
- [ ] Normalization (1NF, 2NF, 3NF)
- [ ] OLTP vs OLAP design
- [ ] Star schema (facts and dimensions)
- [ ] Slowly changing dimensions

**Pipeline & Tools**
- [ ] ETL vs ELT concepts
- [ ] Data quality checks
- [ ] Airflow DAG concepts
- [ ] dbt model concepts
- [ ] Cloud warehouse concepts

### Identifying Gaps

For each skill rated 1-2:
1. What specifically is confusing?
2. What resource would help most?
3. What practice project would solidify it?

### Next Steps Planning

1. Top 3 skills to improve in the next month
2. One project that would demonstrate growth
3. One resource (course, book, tool) to explore
4. One community to join (dbt Slack, Locally Optimistic, Data Engineering subreddit)

## Checkpoint

1. Which Data Engineering skills are you most confident in?
2. Which need more work?
3. What's your next learning goal?
4. **Reflection**: Rate yourself honestly on the skills checklist.
