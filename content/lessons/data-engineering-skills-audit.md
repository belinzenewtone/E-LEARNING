# Data Engineering Skills Audit

## 🎯 By End of This Lesson You Will:
- Self-assess your data engineering skills
- Identify gaps and create a learning plan
- Map skills to career paths

## 🌍 Real-World Analogy First

A doctor runs tests before prescribing treatment. A skills audit runs checks on your knowledge before deciding what to learn next. You can't fix what you haven't measured.

## 📖 Start From Zero — Rate Yourself 1-5

**SQL (1-5)**
- [ ] SELECT, WHERE, ORDER BY, LIMIT
- [ ] Aggregates + GROUP BY + HAVING
- [ ] JOINs (INNER, LEFT, FULL, self)
- [ ] Subqueries + CTEs
- [ ] Window functions
- [ ] Data cleaning in SQL

**Data Modeling (1-5)**
- [ ] Normalization (1NF, 2NF, 3NF)
- [ ] OLTP vs OLAP design
- [ ] Star schema + dimensions
- [ ] Slowly changing dimensions

**Pipeline & Tools (1-5)**
- [ ] ETL vs ELT concepts
- [ ] Data quality checks
- [ ] Airflow/dbt concepts
- [ ] Cloud warehouse concepts

## 🔨 Level Up — Action Plan

For each skill rated 1-2:
1. What specifically is confusing?
2. What resource would help? (course, book, project)
3. Schedule practice time this week

## 🧪 Practice — Try Each Step

1. Rate every skill honestly (1 = heard of it, 5 = can teach it).
2. Identify your top 3 growth areas.
3. Find one project that targets your weakest area.
4. Write a 4-week learning plan.

## 🧠 Mental Model — One Sentence

Self-assessment turns vague "I want to learn more" into specific "I need to practice window functions on real data."

## 📝 Check Your Understanding

- **Reflect**: Which skills are you most confident in? Least?
- **Write it**: Your 4-week learning plan.
